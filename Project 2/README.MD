# Project 2 - Data Classification

## AIGoal

Build a basic classification model using a small dataset.

## Project Description

This project demonstrates the basic steps involved in supervised machine learning classification.

The Breast Cancer dataset provided by Scikit-learn is used to train a model that classifies samples as either benign or malignant.

## Key Requirements

- Load and understand a dataset
- Split data into training and testing sets
- Apply a simple classification algorithm
- Evaluate the model's performance

## Algorithm

Logistic Regression is used as the classification algorithm.

## Technologies Used

- Python
- Scikit-learn
